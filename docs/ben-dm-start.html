Taking over the table

The repo is a campaign engine you drive by talking to Claude Code. You say what you want in plain words, Claude reads the campaign files, and you approve anything before it is written. This page covers the setup, the weekly loop, and the habits that save the most time.

Start here

  • Read scheduler/campaign/_handover.md first. One page from Jeff: where the story stands, the open threads, what each PC is chasing, and what's yours. It holds the DM-only answers, so this page leaves them out.
  • Your campaign file is scheduler/campaign/The Northward Pilgrimage.md. The name is a placeholder. Tell Claude what to call it, and give it a conflict, tone and ending when you know them.
  • Tell Claude how you like to work. Say "fill my Working with section" and answer its questions: phone or desk, how you want questions asked, what to avoid. It goes in meta/players/Ben.md and Claude reads it at the start of every conversation.

One-time setup

You need uv, Node 24, Git, the GitHub CLI (signed in with gh auth login) and Claude Code. First accept your GitHub invitations to JGarnerDev/notes-kit and JGarnerDev/jeff-ui-project (github.com/notifications or your email): two private repos the engine installs from. Then get the engine and set it up: 

gh repo clone JGarnerDev/claude-dnd-engine   # skip if you have it; else git pull
cd claude-dnd-engine
uv sync                                          # Python packages
uv run scripts/setup-hooks.py                    # tidies markdown on commit
uv run --python 3.13 scripts/index-entities.py   # search index, ~20 s

The DM pages (session runner and timeline) need the shared UI package from jeff-ui-project. Let the GitHub CLI read it, then install: 

gh auth refresh -s read:packages
npm config set //npm.pkg.github.com/:_authToken "$(gh auth token)"
npm --prefix app install
npm --prefix app run app       # http://localhost:5177/ · runner at /session.html

Then start Claude in the same folder with claude. It reads the engine's rules on its own and shows what changed since you last worked here. If any step fails, paste the error to Claude. It knows this setup.

The weekly loop

  1. Plan days before

    Run /session. Claude reads the campaign state and proposes a beat spine. You edit the spine first, then it writes the full plan: scenes, read-aloud lines, NPC stat blocks, loot, and two or three real choices for the party.

  2. Polish the night before

    Run /review to fill thin scenes, fix vague lines and catch contradictions. uv run scripts/prep-status.py lists what is still missing: maps, tokens, cards.

  3. Run it game night

    Open the session runner at localhost:5177/session.html. It shows the plan scene by scene, tracks enemy HP with an undo log, and puts a Copy button on every private message so you can whisper it to one player. Record on Discord with Craig if you want a transcript later.

  4. Get the notes in after

    Either drop your own notes in recaps/inbox/ (bullets are fine), or put the Craig recording in recaps/audio/ and run /transcript. Transcription runs on a local GPU and takes 15 to 25 minutes; if your machine can't, send Jeff the files.

  5. Make it canon same week

    Run /recap. Claude asks what happened one question at a time, then writes the session record, updates NPCs and the rest clock, and builds the recap deck for the table. Nothing is canon until it goes through here.

  6. Save it

    Say "commit this". Your commits go on a branch with a pull request into master, and Jeff approves the merge. Claude makes the branch and the PR for you.

Commands worth knowing

/todo
Your dashboard. Items 71, 88, 97, 76, 57, 36, 74 and 98 are yours.
/spitball
Save a loose idea in one line, even from your phone. It goes on disk at once and is never canon.
/region
Build out Cinto, the route north and the Deorum Ostium: geography, places, and questionnaires for cities.
/threads
Forgotten threads and unpaid callbacks, ranked against where the story is now.
/find
Search everything by meaning: "a merchant who owes someone money".
/check
Before you state a fact at the table, check it against canon.
/voice
A short brief on how an NPC talks, from what's been played.
/rumor
Tavern talk and session openers from the rumor pool.
/pitch
Quick ideas for an NPC, hook or place, with nothing written to disk.
/commands
Every command with its options.

Habits that save time

  • Talk plainly. "Plan next session around the boat leaving Cinto" works. You don't need the command names; Claude picks the right one.
  • Answer by number. Claude asks one question at a time with options. "2", or "2, but make her older", is a full answer.
  • Say no to a beat and ask for three more. That's faster than arguing it into shape.
  • Hidden rolls: ask Claude to roll one. It uses scripts/roll.py and tells you the result.
  • Mid-fight, you can tell Claude "the guard took 12". It keeps a running HP tally per enemy.
  • Handouts (item cards, letters) come back as a file plus a link you can paste to the table.
  • Leave the Redwater threads alone unless the party turns back: the Lioness, the stake and Act 1's last scenes wait for Jeff's return.

Where things live

Canon

historian/ is what happened at the table. When anything disagrees with it, the historian wins.

Plans

scheduler/ holds your campaign, acts, missions and session plans, plus the DM-only trackers (_*.md).

Ideas

data/ is the pool of player-made NPCs, places and lore waiting to be used. spitball/ is loose notes.

Rules

meta/ covers difficulty, rewards, tone and prose style. Claude follows them; change one by asking.

Who decides what

Your regions are yours: Cinto, the route north, the Deorum Ostium, and their festivals. World questions outside them (history, religion, the other continents) still go to Jeff, and Claude will say when one comes up. Jeff plays Iggy at your table, so Claude won't show him your plans.
