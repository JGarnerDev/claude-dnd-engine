# What this file is

A stand-in. Sessions 11–14 of **[[Curse of Strahd]]** were canonized before the campaign had
any act structure, so each of them records `mission: "[[Act 1 - Placeholder]]"`, and the
paused mission `Find the Wine Wizard` records `act: [[Act 1 - Placeholder]]`. This file exists
so those five references resolve.

It was briefly retagged `campaign: homebrew` by the `/transition` run on 2026-09-30, on the
assumption it would become the first homebrew act. It will not: the homebrew act is
**[[Act 1 - The Hearth at Ashford]]**, written 2026-10-01. Leaving this file tagged homebrew
would have pointed five Strahd records at a homebrew act, so the tag is back to
`campaign: strahd`.

**Do not fill this in as a homebrew act.** If Strahd's act structure is ever worked out, that
is Kellan's call — the engine is record-only for Strahd (see root `CLAUDE.md`), and Strahd
sessions are planned outside this repo.
