The sea channel between Continent F and [[Mori]] — the southern approach to the eastern continent that trade ships know by heart. [[Merchant's Run]] pairs with a northern channel (the Lower Gate pairing) to create a controlled sea lane. Current runs south; useful if you're heading out, a headwind if you're coming in.

The name is straightforward: this is how commerce moves. Whoever controls passage here controls a significant slice of continental trade.
