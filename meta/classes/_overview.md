# Class Graduations — The Pyramid Pattern

Every vocation in the world is a pyramid: a few at the top shape ages, many in the middle run the world's machinery, and a broad base at the bottom bears the class's name as an insult. The pattern comes from the mage pyramid in `data/lore/magic.md` ("every tradition thins toward its peak") and generalizes from magical traditions to all vocations.

Each class file in this folder answers three questions:

- **Top** — who does nobody meet, but everyone lives in whose shadow?
- **Middle** — who does the uncelebrated, indispensable work?
- **Bottom** — who bears the class's name as an insult?

And one structural question that distinguishes classes from each other:

- **Projection** — when this class builds institutions, what do those institutions make *visible*? Wizard guilds project force (registries, posted prices, certification). Thieves' guilds invert that and project invisibility. Fighters' orders project legitimacy; clerical hierarchies project authority. The projection axis is where class cultures diverge even when their pyramids rhyme.

## How to Use These Files

These are **generation calibration**, not canon lore. They tell you what an NPC of class X at tier Y looks like socially — rarity, respectability, institutional ties — so generated characters land at a believable altitude. Canon articulation of any class's world presence lives in `data/lore/` when and if it gets written; where a lore file exists (wizards: `data/lore/magic.md`), the lore file wins.

- **Read once per task**, like all meta files — and read only the class file(s) the task touches, not the folder.
- **Tier before traits.** When generating or elaborating a character with a known class, place them on the pyramid first. Tier drives social standing, who they know, what they cost to hire, and how the world reads them.
- **Top tier is DM-controlled.** Which top-tier figures exist now, and where: establish in play, never in generation. Same rule as arch mages.
- **Middle tier is the default.** Most classed NPCs the party meets are working professionals. Bottom tier is texture; top tier is an event.
