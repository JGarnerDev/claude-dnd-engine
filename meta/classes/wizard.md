# Wizard Graduations

**Projection: force.** Wizard guilds are the one tradition that formalized its pyramid into institutions built for visibility and force projection — certification, posted prices, registries, enforcement arms.

**Authoritative articulation: `data/lore/magic.md`** — the mage pyramid is written there as world lore, and that file wins on any conflict. This file is only the generation summary.

### High, Grand & Arch Mages — extremely rare

- Reality-benders, rulers, age-shapers. Live centuries. Cluster in turbulent eras.
- Which exist now, and where: DM-controlled. Establish in play.

### Working Wizards — uncommon but essential

- Guild rank-and-file: construction, shipbuilding, military engineering, harvests, industry.
- The world's decisive military asset via combined ritual casting.

### Hedge Wizards & Magicians — common enough to be called magicians

- Market-square entertainers and fixers. Between tradesmen and nuisances.
- Live outside guild sanction — beneath notice in some regions, hunted in others.
